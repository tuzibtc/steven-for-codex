# Steven — AI Product Manager · 史蒂文

史蒂文是 Codex 里的产品研发伙伴。带一个想法、一堆反馈，或一个做了一半的项目来。史蒂文会帮你弄清要解决的问题、把决定落实成需求和验收标准，再按这些标准推进设计、研发和交付。

这个版本包含完整的 13 项产品研发技能，包括项目接管、需求研讨、证据调研、PRD（产品需求文档）、产品与视觉设计、技术方案、实施、审查、验收与状态恢复。

## 交给 Codex 安装

把下面整段发给桌面版 Codex。Mac 和 Windows 使用同一个包。

> 请从 https://github.com/tuzibtc/steven-for-codex 安装完整的史蒂文插件。把仓库添加为 Codex 插件来源，安装 steven@steven-community，并检查版本与启用状态。需要我点击或授权时，请告诉我怎么做。装好后，按仓库的《开始使用》介绍你能帮我做什么，再问我想从哪个场景开始。

如果客户端不能代为安装，可在支持插件管理的本地 Codex 命令行使用：

```sh
codex plugin marketplace add tuzibtc/steven-for-codex
codex plugin add steven@steven-community
```

桌面应用可在添加来源后打开「插件」，从 **Steven** 来源选择 **Steven — AI Product Manager** 安装。安装后建议新开一段对话，再选择史蒂文或输入 `$steven`。如果应用还显示旧插件列表，按客户端提示重开应用。

[下载 0.1.2 ZIP](https://github.com/tuzibtc/steven-for-codex/releases/tag/v0.1.2) 是备用入口。请解压后让 Codex 将目录登记为本地插件来源。需要查看新版本时，可让 Codex 刷新同一个 GitHub 插件来源，再核对安装版本。

本发布已验证 Mac 上的原生 Codex 安装。Windows、不同桌面版本和受管工作区的操作取决于客户端是否支持添加自定义来源，请以实际安装结果为准。

## 第一次使用

[开始使用史蒂文](开始使用.md)用一个合租记账项目讲清需求池、研讨、调研、PRD、研发与验收。想直接试用，可以说：

> 这是我第一次用史蒂文。先介绍一下你自己，再用合租记账举例，带我体验怎样把一个想法拆成真实需求。

从想法讨论起步无需先连 GitHub。要长期受控管理项目，按实际任务连接你自己的仓库、需求看板和工具。配套检查脚本使用 Node.js 22 或更新版本。首次引导由安装请求或上面的开场白开启。
