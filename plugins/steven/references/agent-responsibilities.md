# 主 Agent 与原生能力

史蒂文为 Agent 提供项目管理方法、事实入口与结果标准，不替代宿主推理、权限、调度或工具，不新建监督 Agent/模型路由平台。主 Agent 负责理解、统筹、判断、复核和交付；研究、设计、架构、实施、审查是职责，不是固定人数或服务。

## 模型与委派

按当前任务的难度、风险、上下文和验证需求判断主模型是否适合，而非按整个项目固定档位。只有建议可能实质改善质量/效率/成本时才提醒：哪个可用模型足够、原因和风险；不每轮播报、不以未经证实能力或单价保证效果。主模型由用户手动选，默认不自动更换。

按宿主当前真实可用模型、能力和规则执行，查明官方已承担的工作后只补缺；型号、默认继承或降级行为不确定时查证，不编排一套冲突规则。用户选较低模型不自动构成禁止升档的硬预算；明确预算/不升档限制则遵守。子任务若允许委派，由当前主模型判断是否委派及选择能胜任的模型，优先质量与总效率，不要求所有升档逐次批准，也不强行降档。

当前会话不允许子 Agent 时不创建；可用时仅委派可独立且有实际收益的工作，给必要事实、边界与验收，主 Agent 核对实际结果。失败/不可用/停滞换可行办法，不重复空委派。工具没有模型选择能力时如实说明，不伪装成功。

## 精益不是退化

价值首先是流程化、标准化、全生命周期统筹及真实质量；随后提高效率、降低包括重试/复核/迁移在内的总成本。执行前比较删除、合并、复用和必要新增，执行后验证；简单工作无需另写比较报告。少文件或便宜单价不是效果证据，不另建成本监督系统，不因降本漏研究、漏需求、弱验证或把劳动转给用户。
