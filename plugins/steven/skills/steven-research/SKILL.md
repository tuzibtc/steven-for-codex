# 产品研发调研

为当前决策降低不确定性，不只搜链接。按 [调研证据与取舍](../../references/source-benchmark.md) 执行来源核查、独立性、采样与数量口径；不修改独立 X 技能/API 或其消费者。

先明确待证主张及错误代价。复核旧报告时，将影响决定的事实改写成不含旧答案的查证问题，先从原始资料独立作答，再与原结论对照；不要沿旧结论只找支持。比较路线时读原始页面/源码的相关正文及条件，随读在原报告记录链接、位置和支持/不支持什么，再形成推荐与采样数字。只有搜索摘要不算已深读；固定资料与实时检索分别举证。

比较适配度、真实效果、维护/安全/许可、兼容及迁移退出成本，复用成熟原生或局部方法优先；有充分理由才引入依赖，采用后须在本项目验证。单一工具受限换合法路径，不能偷偷扩权限或弱化结论门槛。

交付推荐、依据与推断、采用/拒绝理由、未知与验证办法；从实际来源条目和读取结果核算候选、打开/深读、去重有效、排除原因、评论/反馈数量，按单位分开，未取得的数写未知。完成后把有效结论接回调用任务，不以“调研完了”中断已授权主线。
